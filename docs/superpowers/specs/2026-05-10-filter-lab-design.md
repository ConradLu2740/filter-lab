# FilterLab - 相机色彩科学逆向还原工具 设计文档

## 1. 项目概述

### 1.1 目标

通过分析相机照片的色彩特征，逆向还原其滤镜/色彩科学（如富士Velvia胶片模拟模式），将其保留为标准LUT或滤镜预设，方便未来对其他照片一键应用该色彩科学。

### 1.2 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Electron + React + TypeScript |
| 图像处理核心 | Python + OpenCV + NumPy |
| 前后端通信 | Electron IPC → stdio/JSON-RPC → Python子进程 |

### 1.3 初始范围

聚焦富士相机（X-T5等）的胶片模拟模式（Velvia/Provia/Astia/Classic Chrome等），后续扩展其他品牌。

```

│                  Electron App                    │
│                                                  │
│  ┌──────────────────────────────────────────┐   │
│  │        React + TypeScript (渲染进程)      │   │
│  │  照片导入 | 预览对比 | 滤镜库 | 参数微调  │   │
│  │  批量处理 | 导出设置                      │   │
│  └────────────────┬─────────────────────────┘   │
│                   │ IPC 通信                      │
│  ┌────────────────┴─────────────────────────┐   │
│  │        Electron 主进程 (协调层)            │   │
│  │  文件系统操作 | Python子进程管理 | 错误处理│   │
│  └────────────────┬─────────────────────────┘   │
│                   │ stdio/JSON-RPC               │
│  ┌────────────────┴─────────────────────────┐   │
│  │     Python 后端 (图像处理核心)             │   │
│  │  EXIF解析 | 色彩分析引擎 | LUT生成引擎    │   │
│  │  色卡检测 | 滤镜匹配                      │   │
│  └──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────┘
```

### 2.2 模块职责

| 层 | 职责 |
|---|---|
| 渲染进程 (React) | UI展示、用户交互、图片预览渲染、参数拖拽调整、即时CSS filter近似预览 |
| 主进程 (Electron) | 文件读写、启动/管理Python子进程、IPC消息路由、进度通知、错误处理 |
| Python后端 | 所有图像处理和色彩科学计算，通过stdin/stdout以JSON-RPC格式通信 |

### 2.3 Python通信方式

主进程启动一个长驻的Python子进程，通过stdin/stdout以JSON-RPC格式通信，避免每次调用都重新启动进程的开销。

## 3. 核心算法

### 3.1 分析流程

```
输入照片 → EXIF解析 → 色彩分析 → 采样点提取 → 插值扩展 → 3D LUT → 导出
```

### 3.2 EXIF解析与相机识别

- 读取照片EXIF元数据（Make、Model、FilmMode等字段）
- 识别富士相机型号和胶片模拟模式（Velvia/Provia/Astia/Classic Chrome等）
- 用于后续特征库匹配和分析策略选择

### 3.3 色彩分析引擎

根据输入模式采用不同策略：

| 输入模式 | 分析方法 |
|---------|---------|
| 色卡参考 | 检测色卡位置 → 提取已知色块的RGB值 → 与标准色卡值对比 → 构建精确映射 |
| 原图+滤镜图 | 逐像素/区域对比两张图 → 计算RGB变换关系 → 生成映射表 |
| 单张照片 | 提取色彩统计特征（直方图、色相分布等）→ 匹配已知胶片模式特征库 → 生成近似LUT |

### 3.4 3D LUT 生成

- LUT维度：33 × 33 × 33（行业标准）
- 从采样点构建稀疏映射表
- 使用三线性插值填充完整LUT
- 应用平滑处理避免色彩断层
- 验证LUT质量（色彩覆盖率、平滑度）

### 3.5 滤镜参数化表示

除了直接导出LUT，还提取可解释的参数：

```json
{
  "whiteBalance": { "temperature": 5800, "tint": -5 },
  "tone": { "highlights": -20, "shadows": 15, "contrast": 10 },
  "color": { "saturation": 25, "vibrance": 15 },
  "hueShifts": { "red": 5, "orange": -10, "green": 15, "blue": -8 },
  "curve": { "rgb": [], "red": [], "green": [], "blue": [] }
}
```

参数用途：
- 方便用户理解和微调
- 可以反向转换回LUT
- 存储空间更小

### 3.6 富士胶片模式特征库（初期硬编码）

为每种富士胶片模式预先定义色彩特征：

| 模式 | 特征 |
|-----|------|
| Velvia | 高饱和度（尤其红/绿/蓝）、高对比度、深色阴影、鲜艳的天空和植被 |
| Provia | 中等饱和度、平衡对比度、自然肤色还原、适合通用场景 |
| Astia | 柔和色彩、低对比度、平滑肤色过渡、适合人像 |
| Classic Chrome | 低饱和度、偏暖色调、复古杂志风格、适合纪实 |

单张照片分析时，先提取照片特征，再与特征库匹配，找到最接近的胶片模式。

## 4. 数据流

### 4.1 分析流程（以色卡参考为例）

```
用户拖入照片
    │
    ▼
渲染进程 (IPC) → 主进程 → Python后端 (JSON-RPC)
    │                        │
    │                        ├── 1. EXIF解析
    │                        ├── 2. 色卡检测
    │                        ├── 3. 色彩分析
    │                        └── 4. LUT生成
    │                        │
    │  ◄── 返回结果 ─────────┘
    │  {
    │    "lut_3d": [...],
    │    "params": {...},
    │    "metadata": { "camera": "X-T5", "filmMode": "Velvia" },
    │    "preview_base64": "...",
    │    "quality_score": 0.92
    │  }
    ▼
渲染进程：显示预览对比 | 分析结果 | 参数微调面板 | 保存/导出
```

### 4.2 实时预览数据流

用户调整参数时的两阶段预览策略：

- **即时反馈**：渲染进程用CSS filter做粗略预览（毫秒级），让用户感知到变化
- **精确预览**：防抖500ms后，Python后端用真实LUT计算精确结果（秒级），替换粗略预览

### 4.3 批量处理数据流

Python逐张处理，通过进度回调通知：

```json
{"progress": 1, "total": 10, "current": "DSC_0001.jpg", "status": "processing"}
{"progress": 10, "total": 10, "status": "completed", "results": [...]}
```

渲染进程实时更新进度条，完成后显示结果列表。

### 4.4 数据存储结构

```
~/.filter-lab/                    # 用户数据目录
    ├── presets/                   # 保存的滤镜预设
    │   ├── fuji-velvia-001.json
    │   └── fuji-provia-002.json
    ├── luts/                      # 导出的.cube文件
    │   └── fuji-velvia-001.cube
    ├── profiles/                  # 导出的ICC配置文件
    │   └── fuji-velvia-001.icc
    ├── feature-db/                # 富士胶片特征库
    │   └── fuji-films.json
    └── config.json                # 用户配置
```

## 5. 界面设计

### 5.1 整体布局

左侧导航 + 右侧内容区的经典桌面应用布局：

- 导航栏：导入 | 分析 | 调整 | 滤镜库 | 导出
- 状态栏：Python引擎状态、当前操作进度

### 5.2 核心页面

**① 导入页面**
- 拖拽区域支持单张/多张照片拖入
- 文件选择器支持常见格式（JPG/PNG/TIFF/RAW）
- 显示已导入照片缩略图列表
- 自动读取EXIF并显示相机信息

**② 分析页面（核心页面）**
- 三种分析模式切换：单张分析 / 原图+滤镜图 / 色卡参考
- 左右分栏：原图/参考图 | 分析结果预览
- 均支持缩放/平移
- 显示分析结果：相机型号、胶片模式、质量评分、色彩覆盖率
- 操作按钮：保存为滤镜 / 导出LUT / 参数微调

**③ 参数微调页面**
- 上方：原图/效果图对比（滑块拖动实时更新）
- 下方：参数面板
  - 白平衡（色温、色调）
  - 色调（高光、阴影、对比度）
  - 色彩（饱和度、自然饱和度）
  - 色相偏移（红、橙、绿、蓝等）
  - 曲线编辑器（可选展开）
- 操作按钮：重置 / 撤销 / 保存预设

**④ 滤镜库管理页面**
- 搜索框 + 新建/导入按钮
- 分组展示：富士胶片模拟 / 自定义
- 每个滤镜卡片显示缩略图和名称
- 选中后可操作：应用到照片 / 编辑 / 导出 / 删除

**⑤ 导出页面**
- 导出格式选择：.cube LUT文件 / 内置滤镜预设 / .icc文件
- LUT设置：尺寸（33×33×33）、输出色彩空间（sRGB）
- 文件设置：保存位置、文件名
- 批量导出选项：同时导出预览图、同时保存参数JSON

### 5.3 设计风格

- 暗色主题为主（适合图像处理场景）
- 主色调：深灰 + 富士绿（#1a6b3c）作为品牌色
- 字体：系统默认无衬线字体
- 图标：简洁线性风格
- 预览区域使用棋盘格背景表示透明区域

## 6. 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| Python进程崩溃 | 主进程监听子进程exit事件，自动重启并恢复上次操作状态；连续崩溃3次提示用户检查环境 |
| EXIF信息缺失 | 提示用户手动选择相机型号和胶片模式，或使用单张照片分析模式 |
| 色卡未检测到 | 提示用户手动框选色卡区域，或切换到其他分析模式 |
| 照片格式不支持 | 提示支持的格式列表，建议用户先转换格式 |
| LUT生成失败 | 显示具体错误原因（如采样点不足），提供降级方案（降低LUT精度） |
| 磁盘空间不足 | 导出前检查可用空间，不足时提前警告 |
| 大文件内存溢出 | 对超大照片（>50MP）自动降采样处理，提示用户精度可能受影响 |

### 6.1 Python环境管理

首次启动流程：
1. 检测系统Python环境（python3/python）
2. 检查依赖库是否安装（opencv, numpy, pillow, exifread）
3. 缺失依赖 → 自动安装（pip install）→ 显示进度
4. 安装失败 → 提供手动安装命令，引导用户操作
5. 启动Python子进程，建立通信通道

## 8. 输出格式规范

### 8.1 .cube LUT文件

遵循Adobe CUBE格式规范：
- TITLE 行
- LUT_3D_SIZE 33
- DOMAIN_MIN 0.0 0.0 0.0
- DOMAIN_MAX 1.0 1.0 1.0
- 数据行：R G B（浮点数，范围0.0-1.0），共33³=35937行
- 排列顺序：R变化最快，B变化最慢（即内层循环为R，外层循环为B）

### 8.2 内置滤镜预设（JSON）

```json
{
  "name": "Fuji Velvia - X-T5",
  "version": "1.0",
  "camera": "Fujifilm X-T5",
  "filmMode": "Velvia",
  "created": "2026-05-10T10:00:00Z",
  "params": {
    "whiteBalance": { "temperature": 5800, "tint": -5 },
    "tone": { "highlights": -20, "shadows": 15, "contrast": 10 },
    "color": { "saturation": 25, "vibrance": 15 },
    "hueShifts": { "red": 5, "orange": -10, "green": 15, "blue": -8 },
    "curve": { "rgb": [], "red": [], "green": [], "blue": [] }
  },
  "lut_3d_size": 33,
  "lut_3d_data": []
}
```

### 8.3 .icc配置文件

使用Python的 `littlecms` 或类似库生成标准ICC色彩配置文件（v2/v4）。
